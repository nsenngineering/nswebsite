# Goal 6: AI Search Visibility (GEO)

## Objective

The purpose of this test was to determine whether AI-powered search and retrieval systems can discover and accurately describe **N.S. Engineering & Geotechnical Services Pvt. Ltd. (NS Engineering)** for realistic prospective-client queries.

The test focused on category-level queries rather than only branded searches because category queries provide a better indication of whether NS Engineering is discoverable by a potential client who does not already know the company.

The four primary queries were:

1. "Who does pile testing in Nepal?"
2. "What is PDA testing and who provides it in Kathmandu?"
3. "Best geotechnical engineering firm in Nepal"
4. "Who does soil investigation for hydropower projects in Nepal?"

The intended test surfaces were:

1. ChatGPT with web search enabled
2. Perplexity with web search enabled
3. Claude with web search enabled
4. Google Search / AI Overview
5. Google AI Mode

At the time of this report, results have been collected for ChatGPT, Perplexity, Claude, and Google AI Search/AI Overview.
---

# 1. Testing Methodology

## 1.1 Query selection

The queries were selected to represent realistic questions that potential NS Engineering clients might ask.

Three of the four queries are strongly category-oriented:

- pile testing in Nepal
- PDA testing in Kathmandu
- soil investigation for hydropower projects in Nepal

The fourth query asks for the "best" geotechnical engineering firm and therefore tests whether NS Engineering is considered among notable firms rather than simply whether its brand is retrieved.

No query explicitly included "NS Engineering", allowing the test to measure unprompted visibility.

## 1.2 Evaluation criteria

For every query/surface combination, the following were evaluated:

- Whether NS Engineering appeared at all
- Whether it appeared without being named in the query
- Whether the information was relevant to the question
- Whether the claims appeared consistent with NS Engineering's published information
- Which competing companies appeared when NS Engineering did not appear
- What type of information competitors appeared to have that could explain their visibility

AI-generated claims were not automatically treated as factual. Claims were considered candidates for verification against NS Engineering's website and other authoritative sources.

- Project location

The Perplexity result explicitly associates NS Engineering with Dynamic Pile Load Test/PDA, PIT, CSL, static pile testing and lateral load testing.

Therefore, the PDA service page should be treated as a priority page for keeping factual, structured and highly specific.

Instead of a generic statement such as:

> "NS Engineering provides Pile Driving Analyzer (PDA) / high-strain dynamic pile testing to evaluate pile capacity and dynamic behavior, using instrumentation such as strain transducers and accelerometers, with results reported for engineering capacity assessment."

Only publish technical details that are actually true for the company's equipment and current service.

# 13. Question 3 — What should be rewritten?

## Example of a weak marketing-style sentence

> "We provide professional and reliable geotechnical services for major infrastructure projects."

This sentence is difficult for a retrieval system to verify because it contains no measurable or distinctive information.

## Better version

A stronger version would be:

> "NS Engineering provides geotechnical investigation and in-situ testing for infrastructure projects, including [verified project names], using [verified methods such as drilling, SPT, MASW, seismic refraction or other applicable methods]."

The final published sentence should contain only information that can be verified from the company's actual project/service records.

## What should be added?

Where publication is permitted, add:

- project name
- project capacity
- location
- investigation method
- test quantity
- dates
- standards
- equipment
- measurable project scope
- links to project documentation or authoritative sources

# 14. Question 4 — Which schema is most useful?

The most directly useful schema for answering:

> "Who does X in Nepal?"

is the **Organization / LocalBusiness-type entity information**, combined with clearly marked **Service** information.

The reason is that the question is fundamentally an entity-to-service relationship:

> NS Engineering → provides → PDA testing

or:

> NS Engineering → provides → geotechnical investigation

The strongest structured-data approach is therefore to make the company entity and its services unambiguous.
